# vsd_freeze_position stays 1: positions/density encode *where* the hidden
# object is and how solid it is — the actual hard-won result of the
# shadow-based reconstruction, most fragile to a noisy VSD gradient.
# vsd_freeze_shape defaults to 0: scale/rotation control each Gaussian's
# anisotropic footprint. A single-viewpoint shadow-based fit commonly leaves
# these needle-shaped, which renders as a coherent silhouette from similar
# angles but crystallized/faceted noise from novel angles — no amount of
# color-only optimization fixes a primitive whose shape is wrong. Anchored
# by vsd_geom_reg_weight against the Phase 1/2 fit either way. Both
# vsd_geom_reg_weight and vsd_smooth_weight are still not fully empirically
# validated — watch position_drift (should stay near 0 given
# vsd_freeze_position=1) in the [VSD] log line, and check preview panels for
# corrupted-looking geometry.
# vsd_checkpoint and vsd_ref_image are intentionally left unset here —

# cluster) since it isn't a repo-relative path. vsd_ref_image defaults to
# data/chair_smooth_walls.png, which — unlike data/chair/ — is small enough
# to travel with `git pull` directly (explicit .gitignore exception).
